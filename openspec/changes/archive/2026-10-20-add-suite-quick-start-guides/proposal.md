## Why

现有技能文档解释了套件原理、逐段翻译了技能源码，并分析了单个技能的设计取舍，但缺少能让初学者照着完成第一次操作的入口。读者需要自行从长篇原理和多个技能文档中拼出起步路径，因此为每套技能增加一篇可跟做的快速入手教程。

## What Changes

- 在现有六个 `docs/skills/<套件>/` 目录中，每套新增一篇 `技能快速入手.md`。
- 查看器欢迎页的“浏览套件”卡片优先打开对应套件的快速入手；缺少快速入手时沿用现有总览与技能文档回退。
- 查看器在没有有效阅读风格偏好时默认使用“精致文章”；已有的有效偏好继续生效。
- 每篇围绕该套件的一个最小可执行案例，写明适用场景、准备条件、示例输入、操作步骤、可观察的结果，以及后续深入阅读路径；不强求在一篇中跑完整条工作流。
- 更新项目根目录 `AGENTS.md` 与 `CLAUDE.md` 中的文档规范，将快速入手明确为第四类文档，并规定其与套件原理、技能中文版和详细设计讲解的分工、生成范围及链接要求。
- 不新增索引页、速查卡、英文镜像或运行代码副本。

## Capabilities

### New Capabilities

无。查看器导航调整归入现有的 `viewer-reading-experience` 能力域。

### Modified Capabilities

- `viewer-reading-experience`：修改“浏览套件”导航卡片的打开目标与回退顺序，并调整默认阅读风格。

## Impact

- `AGENTS.md` 与 `CLAUDE.md`：同步更新两份面向不同 AI 工具的技能文档规范，保留各自的工具路径约定。
- `docs/skills/`：为 `anthropics`、`frontend-design-premium`、`grill`、`impeccable`、`openspec`、`superpowers` 六个现有套件各增加一篇教程。
- `viewer/`：调整欢迎页套件卡片的目标选择和默认阅读风格，并增加相应测试。
- `CONTEXT.md`：补充已确定的“技能快速入手”术语及其边界。
- 不改变 `skills/` 源码、安装脚本、查看器 API 或依赖。
