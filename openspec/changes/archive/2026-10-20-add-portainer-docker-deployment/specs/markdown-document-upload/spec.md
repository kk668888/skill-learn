## MODIFIED Requirements

### Requirement: 本地项目文件持久化

成功上传的文档 SHALL 作为项目目录内的 `.md` 文件保留，关闭并重新启动本地查看器后仍可浏览和搜索。容器部署时，普通文档 SHALL 写入宿主机挂载的项目目录；使用相同宿主机目录重建容器后，文档仍可浏览和搜索。上传操作 MUST NOT 自动执行 Git 暂存或提交，Git 管理由宿主机用户自行完成。

#### Scenario: 重启后查看上传文档

- **WHEN** 用户上传文档后重启本地查看器
- **THEN** 文档仍出现在相同分组，内容与上传时一致

#### Scenario: 重建容器后查看上传文档

- **WHEN** 用户在 Portainer 中以相同宿主机目录挂载重新创建容器
- **THEN** 此前上传的文档仍出现在相同分组，内容与上传时一致，宿主机文件未被容器重建覆盖
