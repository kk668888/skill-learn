# 阅读样式实现验收记录

## 浏览器矩阵

在本机 Chrome 无头模式下，以 `docs/skills/anthropics/skill-creator-中文版.md` 为共同样本，逐一检查四种阅读样式、浅色与深色模式，以及 1440px 和 390px 视口。该文档包含多级标题、列表、引用、表格、行内代码及 Markdown、JSON、Bash 等围栏代码。16 张视口截图保存在 [assets/verification](assets/verification/)；文件名格式为 `<样式 ID>-<light|dark>-<1440|390>.png`。

| 检查项 | 结果 |
|---|---|
| 四种样式 × 明暗 × 两种视口 | 16 组均呈现对应背景、正文与代码配色；阅读区和页面无整体横向溢出 |
| 窄屏长内容 | 在同一文档临时插入 12 列不换行表格与 250 字符代码行，表格和代码各自横向滚动，主阅读区宽度保持 390px 内 |
| 对比度 | 逐组计算正文、代码常用 token、diff 增删叠色与各自背景的对比度，普通文本均不低于 4.5:1；据此加深了浅色代码注释、纸张标题及删除 token |
| 样式选择 | 选择后立即生效，控件显示当前选项；切换不增加文档请求、不改变路由或滚动位置，进度按重排后的正文高度更新 |
| 偏好与明暗 | 跨文档、刷新恢复；无效保存值回退经典文档；本地存储抛错时会话内仍可跨文档选择；明暗偏好与阅读样式互不覆盖 |
| 阅读交互 | 原生选择控件有可见键盘焦点；代码复制及反馈、外链属性、标题锚点、互跳、进度、侧栏与欢迎页作用域通过回归 |

截图展示文档顶部的排版差异；代码高亮与宽内容另以浏览器计算样式、对比度和滚动尺寸核查。原生选择框的弹出层由操作系统绘制，浏览器自动化确认其键盘焦点和选择行为。
