## Why

viewer 当前仅提供浅色和深色配色，技能源码与长篇文章共用一套排版。用户已确认四种阅读主题原型，需要能够按阅读偏好切换整套 Markdown 样式，并保留原有阅读交互。

## What Changes

- 提供经典文档、纸张阅读、简洁笔记、精致文章四种内置阅读风格，覆盖字体、标题、段落、引用、表格与代码块。
- 在文档顶部提供“阅读样式”选择入口，选择即生效，并在浏览器中记住选择；默认经典文档。
- 阅读风格作用于中间文档阅读区，独立于现有全局浅色／深色模式；四种风格均适配两种明暗模式。
- 保留目录、大纲、文档路径、正文内容和现有复制、链接、锚点、阅读进度行为。
- 更新现有代码高亮和引用块规格，使其允许随阅读风格采用不同的视觉表达。
- 第一版不包含主题导入、自定义 CSS、逐篇主题设置、字体下载或新增明暗模式控制。

## Capabilities

### New Capabilities

- `markdown-reading-themes`：四种阅读风格的视觉特征、选择入口、本地记忆、明暗适配与兼容性。

### Modified Capabilities

- `viewer-reading-experience`：代码高亮适配阅读风格与明暗组合；引用块允许不同风格使用底色、强调条或引号图标，同时保持表格悬停反馈。

## Impact

- 前端：`viewer/src/App.tsx`、文档视图和标题区、主题状态、Markdown 样式与代码高亮。
- 新增阅读风格配置和本地偏好存储；继续兼容现有 `viewer-theme` 明暗偏好。
- 不新增后端 API 或运行时依赖，扫描与搜索保持现有接口。
- 验证覆盖偏好恢复、切换交互、四种风格的浅色／深色与窄屏呈现，以及现有阅读功能回归。
- 视觉依据为本变更 `assets/reading-theme-prototypes.png`，用于表达风格方向；实际文档内容和元信息沿用 viewer 的真实数据。
