## Why

查看器目前只能逐篇阅读 Markdown，用户无法一次取回当前可浏览的全部原始文件。增加批量下载后，用户可在本机或局域网查看器中保存一份完整的 Markdown 副本，并继续使用原有目录结构整理文件。

## What Changes

- 在查看器提供“下载全部 Markdown”入口，一次下载一个 ZIP 文件。
- ZIP 收录查看器当前扫描到的所有 `.md`：技能源码、技能中文文档、AI 文章、自建普通文档分组和项目根级文档；保留项目根相对目录结构与文件原始字节。
- 已上传且进入查看器目录的文档在下一次下载时自动纳入；不因侧边栏过滤、搜索结果或当前打开的文档而缩小范围。
- 下载失败时给出明确反馈，不产生或修改项目文件，也不自动执行 Git 操作。

## Capabilities

### New Capabilities

- `markdown-bulk-download`: 定义查看器中全部可浏览 Markdown 的 ZIP 下载入口、归档范围与结构、失败反馈和只读行为。

### Modified Capabilities

无。现有阅读、搜索与上传要求不变。

## Impact

- 查看器前端：增加下载入口、下载中状态与失败提示。
- 查看器同源 API：增加只读 ZIP 下载接口，复用现有项目扫描规则。
- 依赖与测试：选择支持流式生成 ZIP 的服务端依赖，并覆盖归档内容、目录结构、上传后下载及错误路径。
- 本机开发服务和 Docker 生产服务共用该 API；后续部署镜像需要重新构建。
