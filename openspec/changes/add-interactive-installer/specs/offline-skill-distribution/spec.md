## ADDED Requirements

### Requirement: 交互式安装向导

安装器 SHALL 提供交互式向导入口：当用户不带任何参数启动安装器且标准输入为交互终端时，安装器 SHALL 逐步询问安装决策（目标工具、安装范围、套件集合、目标项目目录，Codex 时含宿主 CLI 路径），每次询问 SHALL 提供可直接回车选择的默认值；套件选择 SHALL 支持回车选择全部套件，并 SHALL 支持输入编号列表仅选择部分套件。完成询问后，安装器 SHALL 展示与 dry-run 预览一致的安装计划，并 MUST 在用户显式确认后方执行写入；未确认时（包括直接回车）安装器 MUST 放弃安装且不改动任何目标文件。向导 SHALL 不引入任何 npm 依赖。包内 SHALL 附带 Windows 双击入口脚本：双击后检查 Node 版本并启动向导。

#### Scenario: 向导完成一次安装

- **WHEN** 用户在交互终端不带参数启动安装器，依次选择工具、范围、套件与项目目录并确认
- **THEN** 安装器展示安装计划，用户确认后按计划执行安装并逐项报告结果，全程无需记忆任何命令行参数

#### Scenario: 未确认时不动手

- **WHEN** 向导展示安装计划后用户直接回车（默认值）或回答否
- **THEN** 安装器结束且目标项目与用户级配置保持原样

#### Scenario: 带参数时保持命令行模式

- **WHEN** 用户启动安装器时携带任意命令行参数
- **THEN** 安装器不进入向导，行为与现有 flag 模式完全一致

#### Scenario: 非交互终端不猜测

- **WHEN** 用户不带参数启动安装器，但标准输入不是交互终端（如管道或计划任务）
- **THEN** 安装器不进入向导，打印用法说明并以非零退出码结束

#### Scenario: 双击入口启动向导

- **WHEN** 内网用户在 Windows 资源管理器中双击包内的安装入口脚本
- **THEN** 脚本检查 Node 版本后以交互终端启动安装向导，中文输出不乱码
