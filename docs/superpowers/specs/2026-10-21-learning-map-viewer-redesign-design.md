# skill-learn 查看器「学习地图」视觉改版设计

## 目标与范围

把查看器从通用文档工具界面改成能引导首次实践的「学习地图」，同时保持查阅长文档的效率。设计覆盖欢迎首页、左侧目录、文档头、大纲和窄屏布局。用户已在视觉草图中选择「学习地图」方向及较鲜明的套件色彩，并认可完整桌面布局。

本次改版保留现有六套套件、目录树、过滤与全文搜索、最近打开、上传、完整资料下载、三栏拖拽、明暗模式，以及四种正文阅读样式。默认正文样式仍是「精致文章」。套件卡仍进入该套件的 `技能快速入手.md`；缺失时沿用现有入口回退链。

「学习地图」指清晰的套件入口和路径提示，不表示系统掌握了学习进度。本项目目前没有完成状态数据，因此界面不展示完成百分比、打卡或虚构的进度。

## 视觉语言

页面底色使用偏冷的浅中性色，正文面保持清晰的白色或当前阅读样式的纸面色。鲜明颜色集中在套件入口、侧栏选中态与文档头；普通段落、表格和代码仍由所选阅读样式控制。避免给每段内容套彩色卡片，也不使用装饰性渐变或持续动画。

六套套件各有稳定识别色，颜色由一处映射维护。下表是视觉草图的基准色；实现时须为浅色和深色分别校验文字与背景对比度，并可微调数值。

| 套件 | 基准识别色 | 使用位置 |
|------|-----------|----------|
| OpenSpec | `#626DBE` | 紫蓝标记与浅色块 |
| Superpowers | `#3A9588` | 青绿标记与浅色块 |
| grill | `#B47D45` | 琥珀标记与浅色块 |
| impeccable | `#9A70A6` | 紫色标记与浅色块 |
| anthropics | `#4282AA` | 蓝色标记与浅色块 |
| frontend-design-premium | `#C57A69` | 珊瑚色标记与浅色块 |

未知套件使用中性的默认配色，不因缺少映射而隐藏内容。颜色是辅助识别线索；套件名称、选中态和文档位置始终用文字表达，不能只靠颜色传达。

界面控件以清晰的中文无衬线字为主；「精致文章」等阅读样式继续拥有自己的正文排版。欢迎页的大标题和套件卡通过字号、字重和留白建立层级。彩色卡片是首页主视觉，其余界面保持安静，避免所有区域同时争夺注意力。

## 欢迎首页

欢迎首页不显示空白的大纲栏，内容使用侧栏以外的可用宽度，并为超宽屏设置合理的内容上限。顶部由一句明确的学习引导、简短说明、紧凑统计和「继续上次阅读」入口组成。最近记录为空时，继续入口改为第一个可用的套件入口（优先快速入手）；若目录没有可用入口，则不显示该卡片。

「浏览套件」展示六张有各自浅色底的套件卡。卡片包含套件名、简短用途、真实技能数和文档数；整张卡片可点击，目标仍按当前入口回退链确定。颜色、文字和焦点轮廓共同表达可点击性。窄屏时卡片由三列降为两列，再降为一列，不产生横向滚动。

最近打开区域显示「套件名 · 文档名」，消除多个「技能快速入手」重名造成的歧义；点击后仍按现有 hash 路由打开文档。最近记录为空时隐藏该区域。统计数据继续来自已加载目录树，不增加新接口或手工维护数字。

## 侧栏与文档阅读页

侧栏保留搜索框的两种语义：输入过滤目录，回车执行全文搜索。套件行增加稳定颜色标记；当前套件有可辨识的背景和文字状态。首页初次进入时只展示套件一级入口；若已有最近阅读，可展开其所属套件。打开文档后自动展开该文档的祖先链。用户手动展开或折叠的操作在当前会话中继续有效，不强制一次只能展开一套。

文档页恢复目录、正文、大纲三栏。文档头使用所属套件的浅色面、识别色标记、面包屑、角色标签和清楚的标题；已有的兄弟文档互跳、元数据及「阅读样式」控件仍可见且可用。正文不被套件颜色覆盖：四种阅读样式及其明暗配色继续决定标题、段落、引用、表格和代码块的表现。大纲沿用当前文档标题，活跃项可使用套件识别色，但需要同时有文字或形状状态。

欢迎页与文档页使用同一套侧栏和套件标识。切换文档不重置用户选择的阅读样式、明暗模式和可调整的栏宽。欢迎页隐藏大纲时，不把空白或不可拖动的分隔轨留在右侧；返回文档页后恢复原有大纲栏宽。

## 数据与组件边界

目录树仍是套件名、技能数、文档数和入口目标的权威来源。套件配色作为前端展示映射集中维护，由欢迎页卡片、侧栏、文档头及大纲共享；文档所属套件继续由现有文件上下文推导。最近打开继续使用本地存储中的路径，并在渲染时与当前目录树交叉核对。无需新增服务端字段或接口。

视觉改造应优先沿用现有 `WelcomePanel`、`Sidebar`、`TreeView`、`DocHeader`、`Toc` 和全局布局；只在这些组件的职责需要共享套件展示信息时增加小型公共模块。`DESIGN.md` 当前约定「四种阅读样式只作用于正文、欢迎页和外壳保持克制」，与本次批准的方向不一致；实现时必须同步更新该约定及相关设计令牌，明确套件色仅影响导航和文档头，不侵入正文阅读主题。

## 响应式、状态与可访问性

- 宽屏：欢迎页使用完整内容区；文档页维持可拖拽的三栏。内容上限和侧栏宽度共同约束文字行长。
- 中屏：大纲按现有断点隐藏，首页仍能完整展示套件入口。
- 窄屏：目录继续以抽屉打开，欢迎页卡片单列，文档头与阅读样式控件换行，不遮挡正文。
- 明暗模式：套件色映射提供各自的浅色和深色面；正文仍服从四种阅读样式在明暗模式下的既有规则。
- 键盘与辅助技术：目录、卡片和操作菜单保留语义按钮；焦点轮廓可见；当前文档除颜色外有文字或 `aria-current` 等状态；对比度按实际背景检查。
- 加载、错误、无搜索结果、无最近记录及缺失快速入手的状态延续现有语义，视觉上纳入新外壳。动效仅用于用户触发的展开与切换，并尊重减弱动效设置。

## 验收方式

使用真实六套套件及其长标题检查欢迎页、文档页、过滤和搜索结果；确认全部套件卡进入正确的快速入手或回退文档。检查首页没有空白大纲栏，文档页恢复大纲和已保存栏宽。逐一切换四种阅读样式与明暗模式，确认正文内容、代码块、表格和阅读控件可读，套件色不会改写正文主题。分别在桌面、中屏和约 390px 宽度检查布局及键盘焦点。运行现有相关测试、类型检查和构建；对欢迎页及文档页做实际截图检查。

## 取舍

鲜明套件色能帮助读者快速定位，但也增加深色模式和对比度维护成本，因此配色集中管理，并限制在导航、入口和文档头。欢迎页隐藏空白大纲可以充分使用空间，但需要布局在首页与文档页之间正确切换。侧栏不再默认展开全部套件可减少长目录的压迫感，代价是首次查找深层技能时多一次展开操作；首页套件入口和搜索承担快速进入的路径。
